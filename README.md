# E-commerce-sales-analysis
E-commerce Sales Analysis Project
This project provides a comprehensive end-to-end data analysis of an E-commerce dataset, designed to extract actionable business insights from raw transactional data. It serves as a practical portfolio project for aspiring Data Analysts and Data Scientists.

Project Overview
This project focuses on transforming raw data into meaningful business metrics to drive strategic decision-making. Key areas of focus include customer behavior patterns, sales trends across time, and product performance analysis.

Key Objectives
Monthly Sales Analysis: Identifying peak and low-performing sales months.

Category Performance: Evaluating which product categories and sub-categories generate the most revenue and profit.
Customer Segmentation: Analyzing sales and profit distributions across different customer segments (Consumer, Corporate, Home Office).
Profitability Metrics: Calculating the sales-to-profit ratio to determine the true value of product lines.

Technologies Used
Language: Python
Data Manipulation: Pandas, NumPy
Data Visualization: Plotly (for interactive, dynamic graphs), Matplotlib
Development Environment: Jupyter Notebook
